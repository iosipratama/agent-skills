# agent-skills

My personal skills for AI agents (Claude Code, Codex / ChatGPT desktop, Cursor, Aside).

Each skill is a folder with a SKILL.md inside:

    skill-name/
      SKILL.md

This folder is the master copy. Apps read it through symlinks:
- ~/.claude/skills/   (Claude Code)
- ~/.agents/skills/   (Codex, ChatGPT desktop, Cursor)
- Aside skills folder

Only personal, reusable skills here. Company or client project skills live in that project's repo.
